LOOPA FREE LIVE

Files:
- index.html
- app.js
- style.css
- logo.png

Upload all four files into the SAME GitHub Pages folder, replacing the old versions.

The LIVE system uses Supabase Realtime for presence, chat, and WebRTC signaling, and browser WebRTC for the actual camera stream. No Cloudflare Stream subscription is required.

For best results, test with two phones/browsers on different accounts. Both must allow camera and microphone access.
